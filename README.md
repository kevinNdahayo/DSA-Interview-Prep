## 🚀 How to Use This Repo

1. **Follow the weekly folders** — each `README.md` has a day-by-day plan with checkboxes.
2. **Write all solutions yourself first**, then compare with CTCI Python repo or NeetCode.
3. **Commit daily** — even if it's just notes or a partial solution. Consistency compounds.
4. **Document your thought process** — add comments explaining your approach and Big O.
5. **Track your progress** — check off days in each week's README as you go.

```bash
# Suggested daily commit message format
git add .
git commit -m "Week 04 Wed | CTCI 2.1-2.2 | Remove Dups + Kth to Last"
git push
```

## 💡 Tips for Success

- **Draw before you code.** Every new data structure — draw it on paper first.
- **Talk out loud.** Practice explaining your approach as if an interviewer is watching.
- **Big O everything.** After solving, always state time AND space complexity.
- **Sunday = review day.** Never add new material on Sundays. Consolidate instead.
- **Embrace struggle.** 20 minutes of honest effort > immediately looking at the solution.
